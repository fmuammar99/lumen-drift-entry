LUMEN DRIFT — a neon arena survival shooter (2D canvas, no library): pilot a lone ship through escalating waves, harvest lumen orbs, charge the Nova blast. Drifters, Weavers, Splitters and the Warden boss; dash, combos up to x8, procedural WebAudio.

## Run it

```sh
node serve.ts --port 8080
# then open http://127.0.0.1:8080 in desktop Chrome
```

Controls: WASD/arrows move, mouse aim, hold-click fire, Space dash, E/right-click Nova, P pause, M mute, R restart.
